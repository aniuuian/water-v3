### 11. 修复首页 Hero 轮播图失效
- **现象**: 用户反馈轮播图出问题
- **根因**: `.hero-slider` 有 HTML 结构和 CSS 样式，但全项目（app.js / website.js / 内联脚本）**没有任何 JS 控制幻灯片切换**，导致轮播卡在带 `is-active` 的某一屏，箭头/圆点点击无反应、无自动轮播
- **修复**: 在 index.html 末尾（热门产品脚本之后）新增自包含 IIFE 轮播控制器：

  - 绑定 `data-hero-prev` / `data-hero-next` 箭头、圆点 click
  - `setInterval` 每 6 秒自动轮播，hover 暂停、`visibilitychange` 切后台暂停
  - 取模实现首尾循环
- **顺带修正标记不一致**: 原 slide2 带 `is-active` 而 dot0 带 `aria-selected="true"`（矛盾）；改为 slide1 起始（slide1 is-active + dot0 is-active/aria-selected=true），轮播从第一屏开始
- **验证**: node vm 语法校验通过；jsdom 模拟点击 next/dot0/prev/自动轮播，activeSlide 与 activeDot 同步且首尾循环正确
